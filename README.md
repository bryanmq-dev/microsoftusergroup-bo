## Sobre la comunidad

Microsoft User Group Bolivia es una comunidad que impulsa el crecimiento profesional y tecnico de estudiantes, developers, profesionales IT y entusiastas de tecnologia en Bolivia.

### Que hacemos

- Charlas y meetups sobre Azure y tecnologias Microsoft.
- Talleres practicos de desarrollo, cloud e inteligencia artificial.
- Espacios de networking entre profesionales y nuevos talentos.
- Difusion de oportunidades, programas y eventos de tecnologia.
